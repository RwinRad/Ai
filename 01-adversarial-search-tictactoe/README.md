# 4x4 L-Shaped Tic-Tac-Toe AI

An implementation of a 4x4 Tic-Tac-Toe variant where win conditions are formed by 4-cell L-shapes. Built with Python and Pygame, featuring an AI opponent powered by Minimax with Alpha-Beta Pruning.

## Features
- **Custom Game Rules**: 48 unique 4-cell L-shape combinations count as winning patterns.
- **Minimax with Alpha-Beta Pruning**: Efficient decision tree search optimized with depth limit (Depth = 3).
- **Heuristic Evaluation**: Evaluates potential open L-shapes to make smart decisions within depth limits.
- **Interactive GUI**: Smooth Pygame visual interface.
